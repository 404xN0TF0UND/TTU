Instructions
How to use:
  1. Enter the Ciena device IP address
  2. Provide SSH credentials (username/password)
  3. Specify the port number to modify
  4. Enter the new bandwidth value in kbps
  5. Click "Run Bandwidth Change Script"
  6. Wait for the script to complete
  7. Review the results and configuration changes
Important Notes:
  • This script modifies live device configuration
  • Changes are automatically saved to device memory
  • Ensure you have proper authorization before running
  • Bandwidth values should be in kilobits per second (kbps)
  • Results are logged to timestamped files in the scripts directory
Example Values:
  • 110 Mbps: 110000
  • 1 Gbps: 1000000
  • 10 Gbps: 10000000
  • 100 Gbps: 100000000
